# Squad CLI 0.11.0 — Release Notes, Breaking Changes & Workshop Coverage

> **Version:** `@bradygaster/squad-cli@0.11.0` · **Released:** 2026-06-29 · **Doc written:** 2026-07-03
> **Method:** New-functionality and breaking-change list taken from the upstream [CHANGELOG](https://github.com/bradygaster/squad/blob/main/CHANGELOG.md) `[0.11.0]` entry, then **every workshop-relevant claim re-verified against the installed 0.11.0 binary** (Node 22.22.2, gh 2.93.0, Copilot CLI 1.0.66) via `squad <cmd> --help` and a clean `squad init --no-workflows` in a throwaway repo.
> **Scope:** This document covers what changed **in 0.11.0 specifically** (the previous stable, 0.10.0, is covered by [`../maintainers/04 Squad-0.11.0-Modernization-Review.md`](../maintainers/04%20Squad-0.11.0-Modernization-Review.md) and the modernization commit history). ## 1. TL;DR

0.11.0 is a **feature + polish** release, not a big rewrite. For the workshop, three changes matter:

1. **Bundled skills moved `.copilot/skills/` → `.github/skills/`.** A clean 0.11.0 `init` writes **all** bundled skills to `.github/skills/` (19 of them) and **does not create `.copilot/skills/` at all**. *(Verified.)* — **workshop wording fixed, see A1.**
2. **`cast` is now the primary term for roster/add-member;** `hire` is kept as a silent alias.
3. **`.NET Aspire` → `Aspire`** in CLI help/output text (product is still .NET Aspire; only the printed strings were shortened). The workshop's expected-output blocks already match.

Everything else is additive (`preset install`, `registry`, `squad_state` memory tools) or internal (toolchain refresh, test/CI fixes). **No command the workshop teaches broke.**

## 2. New functionality (Added)

### `squad preset install <source>` — install shared presets
Presets are curated agent collections. 0.11.0 adds installing them from a GitHub URL or local path (previously you could only `list` / `apply` local ones).

```bash
squad preset list                                            # what's available locally
squad preset install https://github.com/owner/repo#my-preset # install a shared preset
squad preset apply my-preset                                 # apply it to this repo
squad init --preset my-preset                                # or apply during init
```

Source shapes accepted: `https://github.com/owner/repo`, `…#preset-name`, `…#path/to/preset`, `…/tree/branch/path`, `git@github.com:owner/repo.git`, or a local `./path`.

### `squad registry add/list/remove` — discovery-only peer squads
Registers other Squad instances for cross-squad discovery/delegation, and ships a bundled cross-squad communication skill.

```bash
squad registry list          # show registered peer squads
squad discover               # find work across registered squads
squad delegate <target> …    # hand work to a peer squad
```

### `cast` terminology (with `hire` alias)
`squad cast` shows the current roster; `squad cast --name … --role …` adds a member. `squad hire` is now a silent compatibility alias that always opens the creation wizard.

```bash
squad cast                              # show the roster (project + personal agents)
squad cast --name Bishop --role backend # add a member (see `squad roles` for role names)
```

### `squad_state` MCP server exposes memory tools
Memory operations are now reachable through the `squad_state` MCP server, and Fact-Checker auto-scaffolding/plumbing improved. A fresh `init` prints a tip for non-interactive use:

```jsonc
// package.json
"scripts": { "squad:copilot": "copilot --agent squad --additional-mcp-config @.mcp.json" }
```

### Copilot App sub-session spawning + reasoning-effort
Cast members can spawn Copilot App sub-sessions, and reasoning-effort settings now thread through agent dispatch (SDK/dispatch internals — no workshop-facing command).

## 5. Breaking changes & migration notes

### BC-1 — Bundled skills live in `.github/skills/`, not `.copilot/skills/`
**What changed:** A clean 0.11.0 `squad init` scaffolds all bundled skills under `.github/skills/` and **creates no `.copilot/skills/` directory**. *(Verified: clean init → `.github/skills/` = 19 dirs; `.copilot/` contains only `mcp-config.json`.)*

**Who's affected:** Any doc, script, or agent prompt that tells a reader to look in `.copilot/skills/` for the **bundled** skills, or that implies `init` populates it. A `.copilot/skills/` folder in an existing repo is a **leftover from a pre-0.11.0 init** (init is idempotent and never deletes) — not something 0.11.0 produces.

**Migration:** Point readers at `.github/skills/`. `.copilot/skills/` remains a *valid* location concept for personal/Copilot-CLI-level skills, but it is no longer where Squad puts bundled skills.

### BC-2 — `cast` is the canonical roster/add-member verb
**What changed:** Help and docs lead with `cast`; `hire` still works as a silent alias.
**Who's affected:** No breakage — `squad hire` and plain-English "hire the team" prompts still work. Prefer `cast` in new material.

### BC-3 — Aspire CLI strings shortened
**What changed:** CLI output/help say `Aspire` instead of `.NET Aspire`.
**Who's affected:** Nobody functionally. Expected-output blocks that quote `Aspire` are correct; prose calling the product ".NET Aspire" is also correct.
